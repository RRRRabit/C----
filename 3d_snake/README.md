# 3D Snake Game

基于 C++ 和 raylib 实现的 3D 贪吃蛇小游戏。

## 运行环境

- Windows 操作系统
- MinGW g++ 编译器

## 编译和运行

1. 确保系统已安装 MinGW g++，且 `g++` 命令可用
2. 双击 `build.bat` 编译项目
3. 运行 `snake.exe`

## 主页面设置

游戏启动后先进入主页面，使用鼠标点击按钮设置游戏。

### 地图关卡

关卡只决定地图大小：

| 关卡 | 地图大小 |
|------|----------|
| Level 1 | 10 x 10 |
| Level 2 | 15 x 15 |
| Level 3 | 20 x 20 |
| Level 4 | 25 x 25 |

### 单独调节

- 速度等级：点击 `-` / `+` 调整，范围是 `1` 到 `5`
- 难度目标：点击 `-` / `+` 调整，范围是 `1` 到 `5`
- 目标分数按比例计算：`地图大小 x 难度等级 x 2`
- 点击 `START` 开始游戏

## 操作说明

| 按键 | 功能 |
|------|------|
| W / 上方向键 | 向上移动 |
| S / 下方向键 | 向下移动 |
| A / 左方向键 | 向左移动 |
| D / 右方向键 | 向右移动 |
| Space | 暂停 / 继续 |
| R | 重新开始 |
| M | 返回主页面 |
| Esc | 退出游戏 |

## 游戏规则

- 控制蛇吃到红色食物得分
- 每吃到一个食物，蛇身变长，分数 +10
- 分数越高，蛇移动速度越快
- 每个关卡有不同目标分数，达到目标分数即可胜利
- 游戏会记录最高分，保存在 `highscore.txt`
- 撞到墙壁或撞到自己身体则游戏结束

## 本版优化

- 主页面支持鼠标点击按钮
- 增加了 5 个地图关卡
- 地图大小、速度等级、难度目标可以分开设置
- 可以从游戏中返回主页面重新选择
- 删除了平滑移动，蛇会直接按格子移动，代码更容易理解
- 删除了镜头旋转和缩放，摄像机固定在斜上方
- 蛇头增加了简单眼睛，方向更容易判断
- 蛇身和尾巴有轻微大小、颜色变化，整体更有层次
- 食物增加了浮动、脉冲外圈和吃到后的扩散反馈
- 地图改成棋盘格地面，边界和角落更明显
- 暂停、失败、胜利提示改成居中半透明面板
