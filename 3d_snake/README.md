# 3D Snake Game

基于 C++ 和 raylib 实现的 3D 贪吃蛇小游戏。

## 运行环境

- Windows 操作系统
- MinGW g++ 编译器

## 编译和运行

1. 确保系统已安装 MinGW g++，且 `g++` 命令可用
2. 双击 `build.bat` 编译项目
3. 运行 `snake.exe`

## 操作说明

| 按键 | 功能 |
|------|------|
| W / 上方向键 | 向上移动 |
| S / 下方向键 | 向下移动 |
| A / 左方向键 | 向左移动 |
| D / 右方向键 | 向右移动 |
| Q / E | 旋转地图视角 |
| 鼠标右键拖动 | 旋转地图视角 |
| Space | 暂停 / 继续 |
| R | 重新开始 |
| Esc | 退出游戏 |

## 游戏规则

- 控制蛇吃到红色食物得分
- 每吃到一个食物，蛇身变长，分数 +10
- 分数越高，蛇移动速度越快
- 游戏会记录最高分，保存在 `highscore.txt`
- 蛇占满整个地图后获得胜利
- 撞到墙壁或撞到自己身体则游戏结束
