# 3D Snake Game

基于 C++ 和 raylib 实现的 3D 贪吃蛇小游戏。

## 运行环境

- Windows 操作系统
- MinGW g++ 编译器

## 编译和运行

1. 确保系统已安装 MinGW g++，且 `g++` 命令可用
2. 双击 `build.bat` 编译项目
3. 运行 `snake.exe`

## 主页面设置

游戏启动后先进入主页面，使用鼠标点击按钮设置游戏。

### 地图关卡

关卡只决定地图大小：

| 关卡 | 地图大小 |
|------|----------|
| Level 1 | 10 x 10 |
| Level 2 | 15 x 15 |
| Level 3 | 20 x 20 |
| Level 4 | 25 x 25 |

### 单独调节

- 速度等级：点击 `-` / `+` 调整，范围是 `1` 到 `5`
- 难度目标：点击 `-` / `+` 调整，范围是 `1` 到 `5`
- 目标分数按比例计算：`地图大小 x 难度等级 x 2`
- Crazy Mode：点击按钮切换疯狂模式
- 点击 `START` 开始游戏

## 操作说明

| 按键 | 功能 |
|------|------|
| W / 上方向键 | 向上移动 |
| S / 下方向键 | 向下移动 |
| A / 左方向键 | 向左移动 |
| D / 右方向键 | 向右移动 |
| Space | 暂停 / 继续 |
| R | 重新开始 |
| M | 返回主页面 |
| Esc | 退出游戏 |

## 游戏规则

- 控制蛇吃到红色食物得分
- 每吃到一个食物，蛇身变长，分数 +10
- 金色超级果子分数 +50，并让蛇额外增长 5 节
- 分数越高，蛇移动速度越快
- 每个关卡有不同目标分数，达到目标分数即可胜利
- 游戏会记录最高分，保存在 `highscore.txt`
- 撞到墙壁或撞到自己身体则游戏结束

## 疯狂模式

开启 Crazy Mode 后会加入额外规则：

- 分数没有上限，不会因为达到目标分数而胜利
- 随机触发红光预警，蛇会先闪红
- 闪红结束后，蛇保持红色并进入 8 秒加速状态
- 加速时速度变为普通速度的 1.6 倍
- 加速结束后，蛇会闪烁绿光并恢复正常状态
- 只有加速期间可以穿越地图边界，从另一边出现
- 可穿越期间，地图边界会变成淡红色
- 地图上会随机出现蓝色方块
- 蓝色方块先闪烁预警，之后变成实体
- 蛇撞到实体蓝色方块会失败
- 蓝色方块生成速度比普通随机事件更快

## 本版优化

- 主页面支持鼠标点击按钮
- 增加了 4 个地图关卡
- 地图大小、速度等级、难度目标可以分开设置
- 新增 Crazy Mode 疯狂模式
- 新增超级果子
- 可以从游戏中返回主页面重新选择
- 删除了平滑移动，蛇会直接按格子移动，代码更容易理解
- 删除了镜头旋转和缩放，摄像机固定在斜上方
- 蛇头增加了简单眼睛，方向更容易判断
- 蛇身和尾巴有轻微大小、颜色变化，整体更有层次
- 食物绘制简化为红色普通果子和金色超级果子，减少不影响玩法的复杂特效
- 代码按设置、蛇移动、疯狂模式、绘制、UI 分区整理，更适合新手阅读
- 主菜单和游戏运行界面加入背景图片，图片缺失时会自动退回纯色背景
- 进入游戏和返回主菜单时会显示 Loading 过渡：直接黑屏、0.4 秒保持、0.15 秒渐隐
- 地图改成棋盘格地面，边界和角落更明显
- 暂停、失败、胜利提示改成居中半透明面板

## 项目结构

```
3d_snake/
├── assets/
│   └── menu_background.png # 背景图
├── main.cpp          # 程序入口和主循环
├── constants.h       # 常量参数
├── types.h           # 游戏数据结构
├── settings.*        # 关卡、速度、难度设置
├── snake_logic.*     # 蛇移动、吃果子、碰撞、生成食物
├── crazy_mode.*      # 疯狂模式规则
├── input.*           # 键盘和鼠标输入
├── draw_scene.*      # 3D 场景绘制
├── draw_ui.*         # 菜单、按钮、分数和弹窗
├── loading.*         # Loading 过渡
├── assets.*          # 图片资源加载和绘制
├── score_file.*      # 最高分读写
├── build.bat         # 一键编译脚本
├── README.md         # 项目说明
└── third_party/
    └── raylib/
        ├── include/  # raylib 头文件
        └── lib/      # raylib 库文件
```

## 推荐阅读顺序

如果是新手阅读代码，建议按下面顺序：

1. `main.cpp`：先看程序怎么启动、更新、绘制、关闭
2. `types.h`：看游戏里保存了哪些数据
3. `constants.h`：看各种参数在哪里统一修改
4. `snake_logic.cpp`：看贪吃蛇核心规则
5. `input.cpp`：看键盘和菜单点击怎么控制游戏
6. `draw_scene.cpp` 和 `draw_ui.cpp`：看画面如何画出来
7. `crazy_mode.cpp`：最后看疯狂模式的额外规则
