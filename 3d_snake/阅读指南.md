# 代码阅读指南

这份文档是给第一次读这个项目的新手看的。

项目已经拆成多个模块。你不需要一开始就看懂所有文件，建议先理解“程序每一帧做什么”，再看具体规则。

## 1. 先看主流程

从 `main.cpp` 开始。

主流程只有四步：

1. `InitProgram()`：创建窗口，加载资源，读取最高分，设置默认菜单参数。
2. `UpdateProgram()`：每一帧更新输入、Loading、蛇移动、特效、疯狂模式。
3. `DrawProgram()`：每一帧绘制背景、3D 场景、UI、Loading。
4. `CloseProgram()`：退出前释放图片资源并关闭窗口。

可以先记住一句话：

> 每一帧都是先更新数据，再根据数据画画。

## 2. 再看数据结构

看 `types.h`。

最重要的是 `GameContext`。

`GameContext` 是一个“总数据包”，里面放了：

- `settings`：菜单选择的关卡、速度、难度、疯狂模式。
- `game`：蛇、食物、分数、当前游戏状态。
- `effects`：吃食物爆炸、分数闪烁这类临时效果。
- `crazy`：疯狂模式的红光、加速、绿光、蓝色方块。
- `assets`：背景图片。
- `loading`：Loading 黑屏倒计时。
- `camera`：3D 摄像机。
- `highScore`：最高分。

很多函数都写成 `函数名(GameContext &context)`，意思是这个函数会读取或修改游戏总数据。

如果参数是 `const GameContext &context`，意思是这个函数只读取数据，不应该修改游戏规则。

## 3. 核心玩法看哪里

核心玩法在 `snake_logic.cpp`。

重点按这个顺序看：

1. `InitGame()`：一局游戏开始时，蛇、分数、食物、疯狂模式数据如何重置。
2. `UpdateGame()`：什么时候让蛇移动一格。
3. `MoveSnake()`：蛇移动一格的完整流程。
4. `CheckGameOver()`：撞墙、撞自己、撞蓝色方块。
5. `EatFoodIfNeeded()`：吃到食物后加分、增长、胜利判断。
6. `SpawnFood()`：随机生成食物，超级果子只在 Crazy Mode 出现。

蛇移动可以理解成：

> 算新蛇头 -> 判断是否穿墙 -> 判断是否失败 -> 插入新蛇头 -> 吃食物 -> 决定是否删除尾巴。

## 4. 输入看哪里

输入在 `input.cpp`。

分两种状态：

- 菜单状态：鼠标点击按钮。
- 游戏状态：键盘控制蛇、暂停、重开、返回菜单。

`TryChangeDirection()` 里有一个重要规则：

> 蛇不能直接反方向移动。

比如正在向右走，不能立刻向左。

## 5. 疯狂模式看哪里

疯狂模式在 `crazy_mode.cpp`。

它不是一条独立主线，而是在普通贪吃蛇规则之外增加事件。

主要流程：

1. `redFlashTimer`：红光预警。
2. `boostTimer`：加速状态，可以穿墙。
3. `greenFlashTimer`：加速结束后的恢复提示。
4. `blocks`：蓝色方块，先闪烁预警，再变成实体障碍。

如果只想先看普通贪吃蛇，可以暂时跳过这个文件。

## 6. 画面看哪里

3D 场景在 `draw_scene.cpp`：

- `DrawGridGround()`：棋盘格地面。
- `DrawWalls()`：地图边界。
- `DrawSnake()`：蛇头和蛇身。
- `DrawFood()`：普通果子和金色超级果子。
- `DrawEatEffect()`：吃食物后的爆炸圈。
- `DrawCrazyBlocks()`：疯狂模式蓝色方块。

2D UI 在 `draw_ui.cpp`：

- 主菜单。
- 按钮。
- 分数。
- 操作提示。
- 暂停、失败、胜利弹窗。

绘制函数一般只负责画，不应该改变游戏规则。

## 7. 参数在哪里改

看 `constants.h`。

常改的参数有：

- `SCREEN_WIDTH`、`SCREEN_HEIGHT`：窗口大小。
- `SUPER_FOOD_CHANCE`：超级果子概率。
- `BOOST_SPEED_RATE`：疯狂模式加速倍率。
- `LOADING_HOLD_TIME`、`LOADING_FADE_OUT_TIME`：Loading 时间。
- `MENU_WIDTH`、`MENU_HEIGHT`：菜单大小。

## 8. 最高分和资源

`score_file.cpp` 负责读写 `highscore.txt`。

`assets.cpp` 负责加载和绘制背景图。

这两个文件比较独立，最后看即可。

## 9. 建议阅读顺序

1. `main.cpp`
2. `types.h`
3. `constants.h`
4. `snake_logic.cpp`
5. `input.cpp`
6. `draw_scene.cpp`
7. `draw_ui.cpp`
8. `crazy_mode.cpp`
9. `loading.cpp`
10. `assets.cpp`
11. `score_file.cpp`

先看整体，再看细节。不要从最长的文件开始硬读。
